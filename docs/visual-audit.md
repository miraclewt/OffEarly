## 1. 为什么做这次校对

校对前的实测：全库 **89 处**硬编码色值散落在 9 个文件里，同一个「边框灰」在 6 个文件里各写一遍，
没有人能回答「这个项目一共用了几种颜色」。改一次主色要动 9 个文件，且没有任何机制阻止继续加新色。

现在所有**内联样式**一律引用 CSS 变量，色值只在 `src/styles/theme.css` 定义。

| 类别 | 数量 | 处置 |

| 界面 chrome 色 | 20 个不同值 | 全部收敛为上表 token |

| SVG 呈现属性锁定的字面量 | 9 处 | **必须保持字面量**（见 §4） |

### 为什么有一批色值不能 token 化

SVG 的**呈现属性**（`fill=` / `stroke=` 这类 XML attribute，区别于内联 `style`）**不解析 `var()`**：
写成 `fill="var(--oe-x)"` 浏览器会直接渲染成黑色。因此下面这些必须留字面量 hex：

| 位置 | 值 | 原因 |
|---|---|---|
| `GANTT_OFF_COLUMN_FILL` | `#F5F5F5` | SVG `fill` + 测试断言 |
| `GANTT_BASELINE_FILL` | `#9CA3AF` | SVG `fill` + 测试断言 |
| `GANTT_TODAY_COLOR` | `#DC2626` | SVG `stroke` + 内联 style 双用途 + 测试断言 |
| `ARROW_COLOR` / `LANE_FILL` / `TOPIC_ROW_FILL` | — | SVG `fill` / `stroke` |
| `DEFAULT_TOPIC_COLOR` | `#4F46E5` | 话题数据兜底色 |
| 里程碑菱形 `stroke="#FFFFFF"` | `#FFFFFF` | SVG 呈现属性 |
| `mixColor(..., target='#000000')` | `#000000` | 颜色计算基色，非样式 |

已在 `GanttCanvas.tsx` 顶部写明这段约束，避免后来者「顺手改成变量」而让甘特图变黑。

### ❗ 需要裁决的三处（记入差异清单，不在本次擅自改动）

1. **优先级彩点与 spec「语义色仅三处」冲突。** 设计稿 01/04 的卡片在日期前用**红 / 黄 / 绿**圆点表示
   高 / 中 / 低优先级，而 spec 第 7 节规定语义色只有逾期红 / 阻塞琥珀 / 完成绿。二者不能同时成立：
   要么承认「优先级」是第四类语义色，要么改用形状 / 文字承载优先级。**属 T15 卡片的设计决策点**，
   本次未实现卡片，故不擅自定夺。
2. **正常态日期的琥珀色圆点。** 设计稿里未逾期的日期前仍是琥珀 / 橙色圆点。若沿用 spec 的
   「琥珀 = 阻塞」，会把「临近到期」和「被阻塞」在视觉上混为一谈。建议正常态日期改用
   `--oe-text-muted`，仅逾期用红——同样待 T15 定夺。
3. **品牌 logo 未用品牌色。** `brand/logo-mark.svg` 为多色锁定版，当前 UI 只用单色描边图标。
   若要在侧栏/启动页出现品牌色底，需要新增一个「品牌靛蓝底」用法——那会引入 `--oe-accent`
   之外的一处彩色，须先确认是否纳入规范。
