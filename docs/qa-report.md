### 2.2 通过项（重点验证过、确认没问题）

- **拖拽换列真实可用**：手工指针序列（12 步移动）把卡片从待办拖到进行中，`data-status` 变 `doing`，且没有误开任务弹窗——补上了 e2e 里 skip 掉的那条用例的信心。
- **焦点可见**：连按 25 次 Tab，每一站都有 focus ring（`box-shadow` 环），只有 `body` 自身没有。
- **可访问名完整**：1440 下 20 个可交互元素、60+ 面板控件全部有可访问名；初判「未命名」的甘特复选框与筛选跳数输入实为 `<label>` 包裹，属误报。
- **1440×900 无横向滚动、无文本裁切、无破图、控制台零报错**（看板 / 甘特 / 导图 / 知识库 / 弹窗 / 四面板逐个扫）。
- **空态文案齐全**：空库四列、空白导图、空知识库、知识库搜不到、甘特无未排期，都有说明与主操作按钮。
- **删除有二次确认**：里程碑是内联确认条，知识库是「点一次变红再点删除」。
- **归档一致性**：归档话题后侧栏行消失、该话题卡片消失、待办计数 6→5，与看板口径一致。
- **同名任务可连续录入**：连续回车建 3 条同名任务，编号与排序正常，列体自动滚到新卡片。
- **笔记编辑器内的 Ctrl+Z 语义正确**：只撤销刚输入的正文，不会误触任务属性命令栈（这是全局快捷键改造时最容易踩的坑，当前是安全的）。
- **英文界面除备份面板外零残留**：空库 + English 巡检 4 个视图 + 4 个面板，仅「早下班」品牌副标题与语言选项「简体中文」是刻意中文。
- **弹窗在小窗口可用**：1024×700 下弹窗铺满视口，关闭按钮仍在可达区域（y=33）。
- **灯箱 / 图片尺寸 / 导出 / 冲突三选 / 只读自愈**：e2e 已覆盖，本轮抽查无异常。

### 2.3 未复现

- 一次巡检里出现过 `Failed to load resource: net::ERR_FILE_NOT_FOUND`，专测请求失败时无法复现（看板 + 弹窗流程 `requestfailed` 为空）。判断为 `file://` 下的偶发资源探测，不影响功能，记录备查。

## 3. 建议的修复顺序

**第一批（低风险、收益直接，约半小时）**

1. F5 备份面板补 Esc（3 行，与另外三个面板同款实现）。
2. F7 `<TaskDrawer autosave={phase.autosave}>`（1 行接线，插槽已存在）。

**第二批（需要一次产品裁决）**

4. F1 撤销入口：`App` 挂全局 `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`（跳过 `contenteditable` / `input` / `textarea`），顶栏加两个图标按钮并接 `canUndo/canRedo`。这是当前最影响「敢不敢操作」的一项。
5. F3 甘特首屏：挂载后把今天滚入视野（或加「回到今天」按钮）。历史记录里这条一直标着「要不要做未定」，本次建议做——首屏是空白的 9 月格子，容易让人以为图没数据。

**第三批（打磨）**

6. F4 备份面板补 `backupPanel.*` 中英词表 + `App` 传 `labels`（与 conflict / safemode 同一手法）。
7. F6 右键菜单补 Esc + 视口钳制；F9 空库给「新建话题」主按钮；F10 统一日期显示格式；F11 话题树补键盘导航。
8. F8 给外壳一个 `min-width`（约 1080）或窄屏单列策略——桌面工具可以「不支持窄窗」，但不该「压碎」。
